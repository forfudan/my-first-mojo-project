# My First Mojo Project

This repository contains all the example programs featured in the book [Mojo Miji - A Guide to Mojo Programming Language from A Pythonista's Perspective](https://mojo-lang.com/miji). Each program is designed to illustrate key concepts and practical techniques discussed throughout the book, making it easier for readers to follow along and experiment with Mojo code on their own.

By combining the explanations and exercises in Mojo Miji with the source code provided here, readers can deepen their understanding of the Mojo programming language. The examples are organized to match the progression of topics in the book, allowing for a hands-on learning experience.

Whether you are new to Mojo or coming from a Python background, this collection will help you bridge the gap and quickly get up to speed with Mojo's syntax, features, and best practices. Feel free to explore, modify, and run the programs as you work through the chapters of Mojo Miji.
